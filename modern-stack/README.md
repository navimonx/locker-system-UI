# Locker System Modern Stack

This folder contains the JavaScript modernization of the existing locker system UI.

## Structure

- `frontend/` - React + Vite client app
- `backend/` - Express API server

## Phase 1

This phase sets up the app skeleton and preserves the current PHP version in `locker_system/` without breaking it.

## Next phases

1. Build the auth flow and dashboard pages
2. Add locker browsing, reservation logic, and admin tools
3. Connect to MySQL and align data models with the current system
4. Reuse the current design language from the existing UI
